# NIST CSF Endpoint Risk Assessment – Windows 11

## Recruiter Summary
This project demonstrates hands-on experience performing a NIST Cybersecurity Framework (CSF)–aligned risk and control assessment against a Windows 11 endpoint. It showcases practical GRC skills including control evaluation, evidence collection, risk identification, and remediation planning using real technical artifacts rather than policy-only analysis.

The assessment mirrors how entry-level GRC, compliance, and risk analysts evaluate security posture, document gaps, and communicate findings to technical and non-technical stakeholders.

## Overview
This repository documents a scoped NIST CSF risk assessment conducted against a single Windows 11 endpoint operating in a virtualized environment. The goal of the project is to demonstrate how cybersecurity controls are identified, assessed, and documented using the NIST CSF, with emphasis on evidence-based evaluation and risk-informed decision-making.

Rather than focusing on compliance checklists alone, this project evaluates how controls function in practice and how gaps translate into risk.

## Assessment Scope
- **Asset:** Windows 11 Virtual Machine
- **Environment:** VMware Workstation
- **Assessment Level:** Endpoint-focused
- **Framework:** NIST Cybersecurity Framework (CSF)
- **Approach:** Control validation, evidence review, and risk assessment

Out-of-scope items include enterprise-wide policies, third-party vendors, and cloud infrastructure.

## Methodology
The assessment followed a structured GRC workflow:

1. Defined assessment scope and assumptions  
2. Selected applicable NIST CSF subcategories  
3. Evaluated control implementation status  
4. Collected technical and configuration evidence  
5. Identified control gaps and associated risk  
6. Documented remediation recommendations  
7. Captured lessons learned and improvement opportunities  

This approach aligns with common compliance and risk assessment practices used in regulated environments.

## NIST CSF Functions Covered
The assessment evaluates controls across all five NIST CSF functions:

- **Identify** – Asset inventory and risk awareness  
- **Protect** – Access control and secure configuration  
- **Detect** – Logging and monitoring capabilities  
- **Respond** – Incident analysis and response readiness  
- **Recover** – Improvement and resilience planning  

Each evaluated control is documented with evidence, risk context, and recommendations.
